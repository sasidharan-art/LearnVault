LEARNVAULT • PRIVACY

Privacy built around role-aware learning.

This project-level privacy overview describes the main data handling principles of LearnVault. Institutional deployments should publish their own formal policy.

ACCOUNT DATA

What LearnVault stores

LearnVault stores account information and academic context required to provide role-based learning features, assessments, progress and collaboration.

SECURITY

Authentication

Passwords are protected by backend hashing and authenticated sessions use secure HttpOnly cookies in the deployed application.

ADMINISTRATION

Institution responsibility

The administrator of each LearnVault deployment is responsible for managing authorised users, academic data and operational access.
