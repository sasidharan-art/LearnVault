COMMON QUESTIONS

Built to be simple from the first login.

LearnVault keeps the public experience clear while giving each role a focused workspace after authentication.

Who can create a LearnVault account?

Students can self-register. Faculty accounts are created by Admin. Admin accounts are not publicly registered.

How does LearnVault know which content a Student should see?

The Student's selected Course / Program and Current Level / Year determine the matching Subjects and learning content.

What happens when a Student moves to the next Year or Grade?

The Student can request academic progression. Admin approves the change, and LearnVault preserves previous academic history.

Can Faculty manage their own learning content?

Yes. Faculty can manage Resources, Questions, Quizzes, Assignments, Skills and Subject announcements for assigned Subjects.

What can Admin monitor?

Admin can manage academic structure, accounts, Faculty assignments, Student progression, learning modules, Peer activity, announcements and reports.
