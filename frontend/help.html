COMMON QUESTIONS

LearnVault workflows

What does a Student select during registration?

The Student selects a Course / Program and Current Level / Year. Department or Stream context is derived from the Course structure controlled by Admin.

What happens when a Student moves to the next Year or Grade?

The Student sends an Academic Progress request. Admin approves the destination Course / Level, and LearnVault preserves the old academic stage in history.

Can Faculty create their own account?

No. Faculty accounts are created by Admin so teaching access can be linked to the correct assigned Subjects.

Does Faculty need Admin approval for every Question or Quiz?

No. Faculty controls Question Bank and Quiz creation for assigned Subjects. Admin has monitoring and oversight capability.

Who receives Notifications?

Students, Faculty and Admin each receive role-aware updates. Faculty and Admin can also publish announcements within their allowed audience scope.

What can Admin control?

Admin manages accounts, academic structure, Faculty access, Student progression, learning oversight, Peer moderation, announcements, reports and database health.
